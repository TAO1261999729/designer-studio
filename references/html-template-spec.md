## 1. 固定画布

- `html` 标签带 `data-canvas-width`、`data-canvas-height`，值为不带单位的正整数。
- `html`、`body`、唯一 `data-canvas-root` 作品容器三处行内宽高与属性完全一致；清除默认边距，`box-sizing:border-box`。
- 根节点不用 `max-width`、`height:auto`、`overflow:hidden` 藏内容；局部装饰可裁切，内容须容纳在所属区域。
- 不用 JavaScript、视口单位、媒体查询计算或改变作品尺寸；不随窗口 scale/zoom。
- 改尺寸时同步画布属性与三处根节点行内尺寸，按同一尺寸渲染核验。

## 2. 可编辑占位逻辑

- 照片位：空 `<img class="card-img" src="">`，配占位轮廓（图标 + 编号 + 提示）；填了 `src` 后占位自动隐藏。
- 文案：主标题、副标、卖点、落款均为真实 DOM 文本节点，可稳定定位（`id` 或 `data-*`），不栅格化进背景图。
- 装饰元素（字母块、色块、线条、水印）与文案节点分开，避免改文案时误删装饰。
- 模板注释里写明：换照片填哪个 `src`、改文案动哪些节点、不要删节点本身。

## 3. 样式与字体

- 配色集中为 CSS 变量（底色、卡片、描边、文字三档、强调色、占位色），便于整体换色。
- 字体优先用已核验的远端字体；声明真实 `@font-face`、family、weight、回退栈；不用 `local()`、相对路径、`file://`、data:/Base64 声明字体源。
- 中文回退栈：思源黑体 → PingFang SC → Microsoft YaHei。
- 文字效果优先用受控 CSS：描边 `-webkit-text-stroke` 保可读，阴影/发光克制；标题一个主要强调机制。

## 4. 结构组织

- 语义分组：上组/标题带/下组，或按内容分区；重复卡片用统一 class，坐标内联在卡片上。
- 主卡（C 位）尺度大于副卡；卡片圆角、描边、阴影统一档位。
- 素材链接必须是核验有效的 HTTP(S) 地址；不用本地、相对路径、临时预览或占位 URL。
- 静态 SVG 自包含；不含外部图像、字体、脚本或动态引用。

## 5. 质检项

渲染同尺寸完整成品后逐项核对：

- [ ] 画布宽高与声明一致，无溢出、越界、滚动条。
- [ ] 卡片/元素之间无意外重叠；叠压有前后层次依据。
- [ ] 标题、卖点、标签无孤字、拆词、标点悬挂；词组完整换行。
- [ ] 未遮挡五官、手部、Logo、证书标题等关键证据。
- [ ] 字体实际命中目标族，无缺字、伪粗、替换字形。
- [ ] 图片链接可访问，比例无拉伸变形。
- [ ] 占位提示与示例文案明确标注，对外前需替换。

## 6. 交付要求

- 保留完整固定画布 HTML 源，不以整页位图替代可编辑区域。
- 预览图与源同一版本、同一尺寸；源更新后不沿用旧预览。
- 说明可编辑范围、素材替换方式、未解决与未验证事项；诊断图不作正式成品。

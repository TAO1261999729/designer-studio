## 1. 参考图拆解清单

看稿时逐项读出并记录，再据此复刻；复刻只取版式与配色语言，不取他人身份资产。

- **画幅**：宽高比、像素尺寸、横竖版、安全边距。
- **版式骨架**：规则网格还是错落拼贴；分几行/几组；主视觉（C 位）在哪、多大；元素之间是并排还是前后叠压。
- **容器卡片**：卡片形状（圆角/直角）、大小档位、描边、阴影、底色；卡片与空位元素（字母块、色块、图标）如何穿插。
- **构图动线**：第一焦点、第二阅读层、收束点；视线从哪进、往哪走。
- **配色**：底色、卡片色、文字色阶、强调色及其面积；是否中性底 + 单一强调色。
- **字体层级**：主标题、副标、卖点、注释分别的字重、字号、字距、中英搭配。
- **留白节奏**：元素间距、卡片间距、四周边距；紧凑还是宽松。
- **气质风格**：商务稳重 / 极简高级 / 活泼年轻 / 传统厚重；靠什么元素撑出这种气质（正装统一、线条、纹理、材质）。
- **素材与人物职责**：人物是主体还是陪衬；照片景别、姿态、服装统一度；装饰元素承担什么语义。

## 2. 配色尺子（60-30-10）

- **60% 主底色**：中性浅底（暖灰白/米白/浅灰），铺大面积背景。
- **30% 辅助色**：白卡、浅灰块、深灰文字，承担分组与层级。
- **10% 强调色**：只给主标题、关键数字或核心卖点；全图一个强调色，不堆第二个高饱和色。
- 人物/产品原色优先保护；主体高饱和时用中性色中和，不把强调色铺满背景。
- 色值集中在 CSS 变量里，便于整体换色；黑白灰至少分三档（深/中/浅）建立层级。

## 3. 字体层级

| 角色 | 职责 | 字重 / 尺度起点 |
|---|---|---|
| hero | 唯一最高焦点、主标题、品牌名 | 600–900，3–6 倍正文 |
| sub | 栏目、卖点标题 | 500–700，1.5–2.5 倍正文 |
| body | 连续说明、参数、经历 | 400–500，1 倍 |
| meta | 编号、注释、辅助信息 | 400–600，0.75–0.95 倍 |

- 中文用中性黑体族，正文不用书法/像素/强装饰体；中英搭配两个家族内完成。
- 标题一行 1–2 行，核心短标题 4–14 字；不把长正式名称硬压成短词。
- 字距、行距、对齐方式在同层级内保持一致。

## 4. 留白与对齐

- 先定对齐轴：左轴、中轴或网格；同组元素共享对齐线，不各自居中。
- 间距成节奏：卡片间距、行间距、段间距有统一档位，不忽大忽小。
- 四周留安全边距；关键信息不贴边、不被裁切。
- 留白不是空着，是给主视觉呼吸；内容多先合并分组，不靠整体缩字硬塞。

## 5. 高级感检查项

- [ ] 颜色是否克制：全图主色不超过一套中性色 + 一个强调色。
- [ ] 对齐是否严格：同组元素共轴，间距成档。
- [ ] 层级是否清楚：一眼能分出标题、卖点、注释。
- [ ] 对比是否克制：不靠高饱和撞色、重投影、发光特效堆质感。
- [ ] 细节是否齐：描边粗细、圆角大小、字距、图标风格统一。
- [ ] 留白是否充足：主视觉周围有呼吸空间。
- [ ] 素材是否真实：人物为真实照片或品牌公开图，无 AI 假脸对外使用。

## 6. 常见跑偏与纠正

| 跑偏 | 表现 | 纠正 |
|---|---|---|
| 网格生硬 | 所有卡片等大等距，像表格 | 主卡放大、副卡缩档，允许错落与前后层次 |
| 颜色过多 | 背景、卡片、标题、卖点各用一色 | 收回中性底 + 白卡 + 单一强调色 |
| 对齐混乱 | 元素各自居中、间距随机 | 定一条主对齐轴，间距统一档位 |
| 对比过满 | 重描边、多层投影、渐变发光 | 去特效，靠尺度、留白和字重分层 |
| 文字拥挤 | 小字塞满、孤字换行 | 合并分组、放宽行距，必要时调字号而非压字形 |
| 素材失真 | 拉伸变形、人脸被裁、占位图当真用 | 等比 cover 裁切，保护五官；占位对外前替换 |
